# Boots and bags skill

A Claude skill for designing leather boots and bags that can actually be cut, sewn and worn, with sculptural cast-metal hardware. Designs are modelled in Blender on a scan of a real last (or a bag form), flattened into 1:1 pattern sheets, checked for clipping, fit and seam lengths, rendered, and run through a make-and-check loop against named reference makers until they hold up.

Status: first version. The workflow and starting values are written down; the pattern-export and check scripts come next, built and tested on the first pair.

See `SKILL.md` for the workflow and `references/` for the rules.
